# Game Word List

`../word-guesses.js` contains the sorted, five-letter alphabetic subset of [sindresorhus/word-list](https://github.com/sindresorhus/word-list). It validates Word Guess entries locally. Puzzle answers and crossword clues are authored separately for this portfolio.
